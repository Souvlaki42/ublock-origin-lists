# Ublock origin lists

This is a collection of useful third party Ublock origin filter lists.

I have them copied in here so I don't depend on other people's repos being up, just in case.

You may prefer the original sources, I won't update these copies regurarly.

Thanks [Ublock Origin](https://github.com/gorhill/uBlock) for always making sure the internet is still usable, despite the ensitification.

Also, thanks to all the wonderful people making these filter lists.

## The list

Here they are:

1. [Hide YT Shorts](https://github.com/gijsdev/ublock-hide-yt-shorts)
2. [Hide YT Playables](https://github.com/Vivian-Green/ublock-hide-yt-playables-too)
3. [Hide Copilot on github.com](https://github.com/orgs/community/discussions/147437)
